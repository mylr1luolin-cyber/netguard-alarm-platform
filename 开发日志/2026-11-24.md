## 三、数据层与核心业务

**今日完成**

- 9 张表实体与 Mapper：sys_user、device_type、device、alarm_record、notify_record、inspect_log、inspect_detail、alarm_rule、daily_stat。
- `DeviceMapper.xml` / `AlarmRecordMapper.xml` 用动态 SQL 做分页、关键字、类型、状态、时间范围与排序，全部 `#{}`。
- 巡检：`InspectService.runInspect` 逐台 `ProbeUtils.probe`（端口>0 走 TCP，否则 ICMP），写 `inspect_log` + `inspect_detail`，状态变化才触发告警。
- 告警：`createOfflineAlarm` 按 `coreFlag && urgentEnabled` 定级别；连续失败 `offlineCount == failThreshold` 才建告警（用 `==` 不用 `>=`，保证只告警一次）；恢复时把原告警置 RECOVERED 并补一条 RECOVER 记录。
- 通知：`NotifyService` 写页面通知 + 邮件（JavaMailSender），`AlarmEventPublisher` 有 Rabbit 与 Local 两套实现，靠 `app.mq.enabled` 切换。
- 动态巡检：`DynamicInspectScheduler` 用 `ThreadPoolTaskScheduler.scheduleWithFixedDelay`，监听 `RuleChangedEvent` 重排，改间隔不用重启。

**关键决策**

- `@Scheduled` 无法运行时改间隔 → 用 TaskScheduler 手动重排（cron 只留给每日 00:10 的统计汇总）。
- 邮件与 MQ 都做成"开关 + 降级"，保证没有中间件也能启动演示。

## 十五、服务器上其实没有 MySQL（20:10）

**今日完成**

- 用户截图：服务器上 `tools\修复登录.bat` 报 `[ERROR] mysql.exe not found.`，同时 `start-mysql.bat` 窗口一闪就关。
- 结论：那台机器**没有 MySQL**（或装在脚本未覆盖的位置）。应用能开出登录页是因为登录页不查库；提交账号才查 `sys_user`，查不到就把异常变成"账号或密码错误"——所以怎么重置密码都没用。
- 新增 `tools/find-mysql.ps1`：环境变量 `NG_MYSQL_HOME`/`MYSQL_HOME` → 注册表 `MySQL AB` → 从 MySQL 服务 `PathName` 反推 → PATH → 常见目录（Program Files、xampp、phpstudy、wamp、devtools、mysql）→ 按盘深度 3 扫描；`bin\mysql.exe` 与 `bin\mysqld.exe` 都在才算数；`-Quiet`/`-Json`；找不到时打印三条办法并 `exit 1`。
- 新增 `tools/查找MySQL.bat`：双击列出本机 MySQL，找不到时说明"登录必然失败"的原因。
- `start-mysql.bat` 重写：先 find-mysql 定位，3306 已通则跳过，找不到 mysqld 时**说明原因并停顿**，不再一闪而过。
- `tools/修复登录.bat` 重写：结果落 `%TEMP%\netguard-fix-login.log`，用 `findstr` 判 `ERROR 1045/2003/1049` 分别提示密码错、MySQL 没起、库不存在。
- `一键启动.bat` 的 MySQL 探测改为 find-mysql，`:nomysql` 分支指向 `tools\查找MySQL.bat`。
- `发布-小文件更新包.zip` 重建为 18,624 B / 12 个文件。

**遇到的问题与解决**

1. `find-mysql.ps1` 写成 UTF-8 无 BOM，PowerShell 5.1 按 ANSI 读，中文把引号配对搞乱，报一屏 `Unexpected token` → `.ps1` 统一 UTF-8 **带 BOM**，`.bat` 仍 GBK+CRLF。
2. `if errorlevel` 块里 echo 带括号（`(run start-mysql.bat first)`），`)` 会提前闭合块，导致后面的 `exit /b 1` 无条件执行——表现是"明明成功却退出码 1，只打印半截提示" → 块内 echo 不写括号，失败分支改 `goto :label`。
3. 在 pwsh 里 `& cmd /c "一键启动.bat"` 捕获输出会一直挂住（`start` 出的 java 窗口继承管道）→ 验证脚本另开窗口，或只查 8080 是否 200。
